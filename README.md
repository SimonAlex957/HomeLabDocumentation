# HomeLab

A repository to document and organise my homelab infrastructure, configurations, and services.

## 📁 Repository Structure

```
HomeLab/
├── backups/        # Backup strategies, schedules, and configurations
├── docker/         # Docker Compose files and container configurations
├── docs/           # Additional documentation, guides, and notes
├── hardware/       # Hardware inventory, specs, and rack diagrams
├── monitoring/     # Monitoring, alerting, and dashboard configurations
├── network/        # Network topology, firewall rules, and VLAN configs
├── scripts/        # Utility and automation scripts
└── services/       # Documentation for each running service
```

## 🚀 Getting Started

1. Browse the directories above to find documentation on each aspect of the homelab.
2. Each folder contains its own `README.md` with more details about its contents.
3. Use the links below to jump directly to a section.

| Section | Description |
|---------|-------------|
| [Backups](backups/) | Backup strategies, schedules, and restore procedures |
| [Docker](docker/) | Docker Compose stacks and container configurations |
| [Docs](docs/) | Guides, runbooks, and general notes |
| [Hardware](hardware/) | Hardware inventory and specifications |
| [Monitoring](monitoring/) | Monitoring and alerting setup |
| [Network](network/) | Network topology, VLANs, and firewall rules |
| [Scripts](scripts/) | Utility and automation scripts |
| [Services](services/) | Per-service documentation and configurations |

## 🛠️ Usage

This repository is primarily documentation. Clone it and keep it up to date as your homelab evolves:

```bash
git clone https://github.com/<your-username>/HomeLab.git
```
